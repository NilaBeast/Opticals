
## Deploy on Vercel
1. Push this `Opticals/` folder to GitHub.
2. Vercel → New Project → Import → Root Directory = `client`
3. Framework: Vite / Build: `npm run build` / Output: `dist` (auto-detected)
4. Deploy. No env vars needed.
